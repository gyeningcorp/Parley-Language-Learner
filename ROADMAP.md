# Course completion

Implemented: standalone generation service, administrator sessions, server-only credentials, durable course files and resumable jobs; original guided audio flow; 30 Spanish starter lessons; precise coverage for 110 languages; personal lessons and phrasebook.

Required to complete the full catalog:

1. Configure the server model key and administrator token.
2. Run the all-language course job. The initial library has 41 playable lessons; 3,259 slots remain.
3. Review translation accuracy, script, romanization, register, vocabulary progression, and cultural context. Structural tests do not perform language review.
4. Verify real-device voice coverage and pronunciation. Recorded course audio is a separate production task.

Further work: optional user accounts and progress sync; downloadable progress backups; reviewed recordings; pronunciation coaching; practice history; shared storage and distributed jobs for multi-instance hosting.

The original app PR must still be resolved into main before production release. This upgrade is based on its add-parley-app branch.
